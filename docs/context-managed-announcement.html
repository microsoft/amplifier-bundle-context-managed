The Problem

Context windows fill up. Then your model forgets.

🪓

Mechanical Truncation

Today's context-simple chops the oldest messages when the window fills. No intelligence, no preservation of what mattered.

🕳️

Silent Gaps

The model doesn't know messages were removed. It hallucinates fill-ins for context it can no longer see, with no way to recover.

🔄

Lost State

Decisions, file paths, error chains, task progress — all silently dropped. Long sessions degrade into confused loops.

The Solution

A gradient from compressed past to vivid present

Instead of chopping, the LLM itself builds rolling summaries of earlier conversation. The model always sees compressed older context + full-detail recent turns + on-demand recovery of anything.

Compressed Summary
Recent Turns
Verbatim Context

Semantic Distillation

The summarization LLM sees full tool call/result chains and makes smart choices about what to preserve. 83:1 compression while retaining all file paths, decisions, and architecture details.

Nothing Silently Lost

Every message persists to a JSONL transcript on disk. Summary markers tell the model what was compressed and how to look it up on demand.

How It Works

Budget-aware 4-threshold cascade

Context pressure is monitored continuously. Each threshold fires a targeted response — the model never gets close enough to the limit to start behaving erratically.

60%
Summarize
LLM-powered summary of older turns. Async — doesn't block the conversation.
→
70%
Warn
Model is told it's running warm. Adjusts verbosity and tool call density.
→
92%
Emergency
Inline compaction fires even if a summary is in progress. Explanatory markers inserted.
→
100%
Hard Cap
Never returns more tokens than the budget. Guarantees no provider rejection.
Recovery

Any detail, any time — on demand

A bundled read_transcript tool gives the model access to the complete verbatim history at any time — including full tool call inputs and results.

  • Pull specific turn ranges by number
  • Search by keyword across full history
  • Recover complete tool inputs and results
  • Rate-limited to prevent context flooding
  • Works across summarization boundaries
# Model decides it needs earlier context read_transcript( search="database schema", max_turns=5 ) # Returns verbatim messages including # full tool call inputs and results # — nothing is silently dropped
Comparison

context-simple vs. context-managed

⛔ context-simple

  • Mechanically drops oldest messages
  • Model doesn't know what was removed
  • Tool results silently lost
  • No recovery mechanism
  • Single hard threshold
  • Sessions degrade after ~15 turns

✅ context-managed

  • LLM summarizes with full tool visibility
  • Explanatory markers at every boundary
  • Complete tool call/result chains preserved
  • read_transcript recovers any detail
  • 4-threshold graduated cascade
  • Sessions survive indefinitely
Getting Started

Drop-in replacement. No other changes needed.

The bundle includes its own root bundle.md with all foundation behaviors built in. Install two Python modules, add to your config, done.

# 1. Install the modules pip install amplifier-module-context-managed pip install amplifier-module-tool-transcript # 2. Add to your Amplifier bundle config bundles: - amplifier-bundle-context-managed # 3. That's it. No changes to your existing # tools, providers, or agents.

Two Modules

context-managed (the context manager) and tool-transcript (the recovery tool). Both installed via pip.

Full Foundation

Includes its own bundle.md with all core behaviors. No dependency on context-simple.

Disk Persistence

Sessions can be resumed, transcripts inspected, full history always available even after summarization.
